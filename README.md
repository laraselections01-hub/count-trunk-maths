# 🐘 Count Trunk

A fun, interactive maths practice web app designed to help kids build speed, accuracy, and confidence with numbers.

## 🎯 Current Features
* **55 Club Practice:** Focused maths questions designed to help students master the 55 Club challenge.
* **Kid-Friendly Interface:** Clean, playful design built for easy use on tablets, phones, and computers.

## 🚀 Roadmap & Upcoming Features
We are actively expanding the app to cover more primary school maths milestones:
* **More Maths Clubs:** Support for **11 Club**, **22 Club**, **33 Club**, **44 Club**, and higher levels.
* **Core Operations:** Dedicated practice modes for **Addition**, **Subtraction**, **Multiplication**, and **Division**.
* **Progress Tracking:** Stars, streaks, and score history to keep learners motivated.
